# 项目模板仓库

📁 **TEMPLATE** 是一个使用Cmake进行标准化项目模板的集合，用于快速初始化新项目。

## 🚀 模板目录

| 模板名称                       | 分支/路径       | 适用场景                 | 关键特性          |
|----------------------------|-------------|----------------------|---------------|
| STM32F4_SPL_CMAKE_NONE     | `F4_SPL_NONE` | 使用 CMake 管理 STM32F407 裸机项目 | SPL库，最小裸机模板         |
| STM32F4_SPL_CMAKE_OS(todo) | `F4_SPL_OS` | 使用 CMake 管理STM32F407带 RTOS 的项目  | SPL库，FreeRtos |


## 🛠️ 使用方法

### ✅ 通过分支获取模板
📌 每个模板位于独立的分支中，无需使用 sparse-checkout。
```bash
# 查看可用模板分支
git ls-remote --heads https://repo-url.git
# 获取指定模板（例如使用STM32F4_SPL_CMAKE_NONE模板）
git clone -b F4_SPL_NONE https://repo-url.git
```

## 🧰 编译工具链说明
该项目模板使用 CMake 管理构建过程，建议配合以下工具链和开发环境使用：

| **编译链/工具**       | **版本** | **说明**                              | 备注                                              |
|------------------|--------|-------------------------------------|-------------------------------------------------|
| arm-nono-eabi-gnu | 13.3   | 用于编译 STM32 工程，建议使用 ARM 官方或 ST官方提供版本 | Version10以后arm不再提供windows版本可执行文件，需自行源码构建或使用ST提供 |
| Cmake            | ≥3.15  | 跨平台构建系统，用于配置、生成项目构建文件               | 可以使用Clion捆绑版本                                   |
| Ninja (可选)       | ≥1.10  | 可选构建后端，比 Make 更快（也支持使用 make）        | 可以使用Clion捆绑版本                                   |
| Clion (可选)          | 最新版本   | 开发IDE，提供图形化界面配置调试器（也支持使用其他IDE)      | 使用Vscode时进行构建时需编写脚本                             |

## 📌 注意事项

- 所有模板均使用 CMake 构建系统，请确保已安装 CMake。

- 使用 STM32 项目模板需配合 OpenOCD、或 J-Link 等工具进行烧录调试。

- 项目仅提供了部分组件的使用说明和初始化代码，请结合实际需要进行裁剪
